# Ilhabela Tour

Portal de passeios de barco, lancha e jipe em Ilhabela — https://ilhabelatour.com

Site estático publicado pelo GitHub Pages (branch `main`, pasta raiz).

- `index.html` — página principal
- `blog.html` — artigos
- `img/perfil/` — fotos de perfil dos operadores
- `img/mosaico/` — fotos dos mosaicos (opNN-1.jpg, opNN-2.jpg…)
- `img/site/` — ícones, logo e capas
- `video/` — vídeo da seção Sobre
